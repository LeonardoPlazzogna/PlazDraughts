Seven frozen moments of the training runs, from the untrained network to the strongest published champion. Every figure below is measured in docs/results.md; nothing here is an estimate. Back to the board.

The ladder Elo of run A and of run B are two different scales: each is built inside its own run, against its own earlier generations. They say how much a run improved on itself, not which run is stronger. The comparison that does answer that is the direct one, a hundred games between the two champions.
